# ESRC Spark Squad - Robotics Workshop Projects
Small embedded-systems projects built during the e-Yantra / ESRC robotics workshop.

| Folder | Hardware | What it does |
|---|---|---|
| BluetoothRobotCar | Arduino, HC-05, L298N | Phone-controlled car over Bluetooth |
| ESP32CAM_ImageSystem | ESP32-CAM | Live MJPEG stream + still capture over WiFi |
| JoystickInterface | Arduino, analog joystick, L298N | Calibrated joystick -> differential drive |
| LineFollowerPID | Arduino, 5 IR sensors, L298N | PID line follower with auto-calibration |
| SmartBlindStick | Arduino, HC-SR04, buzzer, vibration motor | Obstacle warning for visually impaired users |

Each folder contains the sketch (open the `.ino` in Arduino IDE) and a README with wiring.
